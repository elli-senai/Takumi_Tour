# 🌏 Takumi Tour

**Takumi Tour** é uma plataforma web desenvolvida para apresentar destinos turísticos da Ásia e oferecer atendimento inteligente por meio do **Takumi Bot**, um assistente virtual especializado em viagens.

O projeto foi criado com foco em uma experiência moderna, responsiva e interativa, permitindo que usuários conheçam destinos, consultem informações e encontrem pacotes de viagem de forma rápida e intuitiva.

---

## ✨ Funcionalidades

* 🤖 Atendimento inteligente com o **Takumi Bot**.
* 🗺️ Catálogo de destinos asiáticos.
* 📄 Página individual para cada destino.
* 🔍 Informações detalhadas sobre atrações turísticas.
* 📱 Interface responsiva para desktop e dispositivos móveis.
* 🎨 Design moderno com animações.
* ⚡ Navegação rápida e intuitiva.
* 📂 Dados dos destinos organizados em arquivos JSON.

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/takumi-tour.git
```

2. Acesse a pasta do projeto:

```bash
cd takumi-tour
```

3. Abra o arquivo `index.html` em seu navegador.

Ou utilize uma extensão como **Live Server** no Visual Studio Code para uma melhor experiência de desenvolvimento.

## 🤖 Takumi Bot

O **Takumi Bot** é o assistente virtual oficial da Takumi Tour.

Suas principais funções incluem:

* Apresentar destinos disponíveis.
* Informar duração dos pacotes.
* Exibir preços cadastrados.
* Mostrar atrações inclusas.
* Responder dúvidas relacionadas à agência.
* Manter o atendimento exclusivamente no contexto da Takumi Tour.
